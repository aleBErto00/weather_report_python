# Weather Report CLI

Una semplice applicazione da riga di comando scritta in Python per consultare le condizioni meteorologiche attuali di qualsiasi citta tramite chiamate a un'API meteo.

## Caratteristiche

- Recupero della temperatura attuale, percepita e condizioni generali.
- Visualizzazione di umidita e velocita del vento.
- Gestione degli errori per citta non trovate o problemi di connessione.

## Requisiti

- Python 3.8 o superiore
- Connessione a Internet
- Chiave API (se richiesta dal servizio meteo utilizzato)
